# Security Policy

## Supported Versions

`redis-rover` is maintained as an open-source project on a best-effort basis.

Security fixes are generally provided for the latest available release. Older versions are not actively maintained and may not receive security updates.

Users are encouraged to keep `redis-rover` up to date.

## Reporting a Vulnerability

If you discover a potential security vulnerability in `redis-rover`, please report it privately through [GitHub Security Advisories](https://github.com/danik-tro/redis-rover/security/advisories).

**Please do not open public GitHub issues for undisclosed security vulnerabilities.**

When submitting a report, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a minimal proof of concept.
- The affected version and environment, if known.
- Any suggested mitigations or fixes, if available.

Please avoid including real credentials, tokens, or other sensitive data in reports.

## Response and Disclosure

This project is maintained by an individual contributor, so response and resolution times may vary.

Security reports will be reviewed on a best-effort basis. Confirmed vulnerabilities will be prioritized according to their severity, impact, and available maintenance capacity.

When appropriate, fixes and security advisories will be published through GitHub.

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

Thank you for helping keep `redis-rover` secure.
